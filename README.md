# Enterprise Commerce Platform

A production-style microservices portfolio project
built with Java, Spring Boot, PostgreSQL, Kafka,
and Docker.

## Architecture

- API Gateway
- Customer Service
- Order Service
- Inventory Service
- Notification Service

## Technology Stack

Java 21, Spring Boot, PostgreSQL, Kafka,
Docker, Maven, GitHub Actions.

## Current Status

Milestone 1: Customer Service MVP — In progress.

## Roadmap

1. Customer Service
2. Inventory Service
3. Order Service
4. Kafka event integration
5. API Gateway and security
6. Observability and CI/CD
